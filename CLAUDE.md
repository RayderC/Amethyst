## Architecture

Hybrid Next.js router: `app/` (App Router, all UI, all `"use client"`) + `pages/api/` (Pages Router, all API routes). No middleware — auth is enforced client-side via `/api/user` in `app/dashboard/layout.tsx`.

`lib/db.ts` opens SQLite and runs migrations on import. Key schema: `users` (id, username, password, is_admin, created_at); `projects` (id, title, slug, description, content, tech_stack, github_url, live_url, image_url, gallery, youtube_url, featured, created_at, updated_at); `service_links` (id, name, url, description, category, icon_url, sort_order, created_at); `site_config` (key, value — arbitrary key/value store for home-page content).

iron-session (`lib/session.ts`), cookie `amethyst_session`. Production requires `SESSION_SECRET` ≥ 32 chars (auto-generated by `docker-entrypoint.sh` if not set). CSRF (`lib/csrf.ts`) checks `origin` vs `host` on all mutating routes except `/api/setup` and `/api/login`.

## API Routes (`pages/api/`)

- `login` / `logout` / `user` / `setup` / `register` — auth lifecycle; setup and login are CSRF-exempt
- `projects/` — CRUD for portfolio projects (public GET, admin-only write)
- `sessions/` — CRUD for Hub service links (any logged-in user can GET, admin-only write)
- `site-config` — Home-page content (public GET, admin-only PUT)
- `users/` — User management (admin-only)
- `favicon` — Favicon proxy: tries direct fetch then falls back to Google

App Router upload route: `app/api/upload/route.ts` — POST only, handles multipart image uploads, saves to `public/uploads/`. Has inline CSRF check (origin vs host) because it uses `NextRequest` not `NextApiRequest`.

## CSRF Protection

`lib/csrf.ts` exports `checkCsrf(req: NextApiRequest): boolean`. Returns `true` if no Origin header (same-origin or direct API client), or if parsed Origin host matches Host header. All mutating handlers call:

```ts
if (!checkCsrf(req)) return res.status(403).json({ message: "Forbidden" });
```

Exempt routes: `/api/setup` and `/api/login`.

## Upload Route

`app/api/upload/route.ts` accepts POST multipart/form-data with a `file` field. Allowed types: jpeg, png, gif, webp, jpg, heic, heif. Saves to `process.cwd()/public/uploads/` with a random hex filename. Returns `{ url: "/uploads/<filename>" }`. The upload directory is not configurable via env var — it is always `public/uploads` relative to the app root (mounted as a Docker volume at `/app/public/uploads`).

## Design System

Cyberpunk dark theme in `app/globals.css`. Shared design tokens (consistent with AstroFit/ComicOrbit/SkyBit):

- `--bg: #0a0a12`
- `--primary: #7c0eb3` (amethyst purple)
- `--accent-cyan: #22d3ee`
- `--accent-magenta: #f472b6`
- `--font-mono: 'JetBrains Mono', 'Fira Code', ...`

Body uses system fonts (`-apple-system, BlinkMacSystemFont, Segoe UI, Roboto`). `var(--font-mono)` applies only to nav labels, badges, stat values, code elements, `.sidebar-logo` — never body text. Auth/modal cards use `overflow: hidden` with brackets 10px inside (cyan top-left, magenta bottom-right). Sidebar active state uses `box-shadow: inset 2px 0 0 var(--accent-cyan)`. Page titles use chromatic `text-shadow`. No logo image — text-only branding.

Mobile: sidebar collapses to a slide-out drawer with a hamburger button. Mobile top bar shown at small widths.

## Docker

Port 3000. Two volumes:
- `/data` — SQLite database (`amethyst.db`)
- `/app/public/uploads` — uploaded images, served at `/uploads/*`

`.dockerignore` must exclude `node_modules` (Windows DLL would corrupt the Linux SQLite native binding). Use named volumes — WAL locking can break on Windows bind mounts.

The runner stage uses `docker-entrypoint.sh` which auto-generates `SESSION_SECRET` if not provided (sessions will not survive container restart in that case). Set `SESSION_SECRET` explicitly to keep sessions stable across restarts.

Environment variables:

| Variable | Default | Description |
|---|---|---|
| `SESSION_SECRET` | auto-generated | Cookie encryption key (min 32 chars) |
| `DATABASE_PATH` | `/data/amethyst.db` | Path to SQLite database |
| `SESSION_COOKIE_SECURE` | `false` | Set `true` behind a TLS-terminating proxy |
| `PORT` | `3000` | Server listen port |
